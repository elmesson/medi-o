# Roadmap Elmesson - Portal do Inquilino

Fases entregues (1-9):
1. Portal Web (dashboard, leituras, faturas, PIX, contestações, atendimento, perfil, segurança JWT/MFA)
2. Mobile Android (Capacitor, FCM, foto OCR)
3. Hardening (vitest 6, Docker, CI)
4. Admin Síndico + Webhook PIX + Observabilidade
5. PWA offline (manifest, sw.js, fila sync)
6. BI (YoY, ranking, ISR)
7. LGPD (export/delete, audit, rate limit)
8. IA (regressão + chatbot)
9. Polimento (i18n, a11y, perf)

Próximas (10+):
- Fase 10: Testes E2E (Playwright) + carga (k6)
- Fase 11: Multi-tenant + cobrança automática (cron)
- Fase 12: Marketplace de serviços (manutenção)

Como contribuir: ver README.md e `npm run dev`.
